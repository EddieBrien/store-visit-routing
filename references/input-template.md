# 输入模版规范

同事只需要交一个 xlsx（推荐）或 CSV，单 sheet、首行表头，最小两列。

## 列名（表头别名不敏感）

| 列名 | 必填 | 取值 |
|---|---|---|
| `店名`（或 `售点名称` / `名称`） | 是 | 字符串，可带业务代码后缀（`-BH`/`-DL` 等，脚本会自动清洗） |
| `详细地址`（或 `地址`） | 是（列存在即可，单格可空） | 字符串，POI 搜不到时作兜底 |
| `拜访频次`（或 `频次`） | 否 | `一周一次` / `两周一次` / `四周一次`；空 → 一周一次 |

## 示例

| 店名 | 详细地址 | 拜访频次 |
|---|---|---|
| 金鹏超市(世纪路东段) | 普兰店区世纪路东段32号 | 两周一次 |
| 鑫修峰超市 | 太平街道敬业路太平医院旁 | 一周一次 |
| 福鑫商店 | | 四周一次 |

## 人工回填（checkpoint）怎么填

第一步跑完后，打开 `输出目录/待人工标注清单.xlsx`：

- 第 3 列「状态」填**正确地址** → 按该地址编码；
- 第 3 列填 **`先空着`** → 该店留空（不填坐标）；
- 不改 → 用第 4 列「原地址」兜底编码。

## 常见错误

- 首行不是表头 → 会被当成数据丢掉一行；请确认第一行是列名。
- 店名列名写成别的（如「门店名称」）→ 脚本不识别，会报「缺少店名列」。可用别名里的任意一个。
- 城市/区填错 → 高德按「citylimit + adname==区」过滤，会导致全部 no_match。
- 频次写成「两周」「2周1次」→ 会告警并回落「一周一次」。
